# ผลตรวจ Rider Login และ Phaser รุ่น 2

วันที่ 10 ตุลาคม 2569 ตรวจผ่านเบราว์เซอร์บน localhost ข้อมูลทดสอบด้วยชื่อสมมติ ไม่ใช่การทดลองกับนักเรียนจริง

- รหัส 9999 ถูกปฏิเสธและยังไม่แสดงชื่อ รหัส 1234 แสดงชื่อของ Rider ที่เลือก แล้วมีปุ่มเข้าสู่แผนที่
- Rider 01 ทำก่อนเรียนได้ 2/4 ฝึก 4/4 หลังเรียน 4/4 คำใบ้ 1 ครั้ง บันทึกจริงใน JSON ที่ดาวน์โหลด
- กดคำใบ้และเลือกภาพหนึ่งใบ รีโหลดหน้า เข้ารหัสใหม่ แล้วกลับขั้นฝึกพร้อมภาพในช่องแรกได้
- หน่วย 2 ผ่านก่อนเรียน เรื่องราว ตัวอย่าง ฝึก งานคู่ โจทย์ใหม่ สะท้อนคิด และเข้าสนามตามลำดับได้ การกดงานคู่ในรอบ QA เป็นการทดสอบเส้นทาง ไม่ใช่หลักฐานเด็กปฏิบัติจริง
- ยิงและหลบจนบอส 0/12 หน้าสรุปชนะ 120 คะแนน บันทึก mode preview ให้ Rider 01 ไม่เพิ่มแกนการเรียนจากการเล่นสนามฝึก
- ไม่หลบจนแพ้ บันทึก 0 คะแนน mode mission มีปุ่มลองใหม่ เปิดรอบใหม่ได้ ผลหลังเรียนยัง 4/4 ข้ามเกมแล้วรับแกนพลังตามผลบทเรียนได้
- ปุ่มโล่เปลี่ยนเป็นภาพถือโล่และแสดงวงโล่ กดยิงแสดงท่ายิงและกระสุน พักเกมหยุดค้างภาพและเวลา เล่นต่อได้
- สลับ Rider 02 แสดงชื่อใหม่และไม่มีคะแนน/เกมของ Rider 01 ในโปรไฟล์ หน้าครูแสดงสองคนแยกกัน (Rider 01: ชนะ/เล่น 1/2, Rider 02: 0/0)
- หน้าครูต้องใส่ PIN ก่อนแสดงตาราง มีดาวน์โหลดผลทั้งห้อง ตรวจ JSON 20 คนและคะแนน/เกมแยกถูกต้อง เก็บสำเนา qa-demo-export.json
- ตรวจมือถือ viewport 390×844 หน้าเข้าใช้และสนาม ไม่มีล้นแนวนอน ความกว้างเนื้อหา 375 และ canvas 352×273.77 มีปุ่มแตะทุกคำสั่ง
- ตรวจ console หลังโหลด Phaser ไม่พบ error/warn ในรอบที่ตรวจ
- ทดสอบแป้น ArrowLeft, Space และ S ผ่านสนามจริง ภาพ Techno ย้ายไปช่องซ้าย แสดงกระสุนและโล่ แล้วพักได้
- ตรวจไฟล์ HTML สุดท้าย: สคริปต์ทั้ง Phaser และแอปผ่านการอ่านไวยากรณ์ และแทน placeholder ของแอปครบ (Phaser มี __SIZE__/__DIST__ ภายในชุด shader ของไลบรารี เป็นส่วนของไลบรารี ไม่ใช่ placeholder ของแอป)
- ตรวจ RGBA ชีต Techno 1536×1024 พื้นหลังมี alpha=0 และภาพ Golden Parasite 1536×1536 ใช้ช่องละ 512×512
- ตรวจผ่าน Drive connector พบชีต Techno ใหม่ ไฟล์แยก 6 ท่า และ manifest รวม 8 ไฟล์ในโฟลเดอร์ที่ผู้ใช้กำหนด
