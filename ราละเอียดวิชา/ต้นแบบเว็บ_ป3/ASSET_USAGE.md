# การใช้ภาพของบทเรียน ป.3

ธีมภาพยึดหน้าเลือกวิชา ป.3 ซึ่งเป็นดาวธาตุพฤกษา โทนเขียวมินต์และฟ้าน้ำทะเล ตัวมาสไรเดอร์เทคโนต้องรักษาเกราะดำ เงิน และชมพูสด หมวกตาแมลงสีชมพู เข็มขัดและชายเสื้อคลุมตามภาพอ้างอิง ผู้ตรวจงานต้องเปิดภาพต้นฉบับจากคลังเดิมก่อนสร้างท่าใหม่

พื้นหลังเว็บใช้ดาวและสีของหน้าเลือกวิชา ส่วนลูกดาวกลมบนหน้าเข้าเรียนและหน้าหลักใช้สูตรไล่สีและจุดแผ่นดินจากคลาส `el-nature .planet` ของ `Class-P3-Subject-Galaxy.html` เพื่อให้เชื่อมต่อกันทางสายตา
