# ระบบบทเรียน Techno Academy ป.3

## อ่านก่อนแก้ไข

ระบบ ป.3 แยกจาก ป.1 และ ป.2 ทั้งโค้ด สถานะผู้เรียน คะแนน และแพ็กเกจ GAS ใช้ธีม **ดาวธาตุพฤกษา** สีเขียว–ฟ้าตามหน้าเลือกวิชา `Class-P3-Subject-Galaxy.html` ตัวเอกคือมาสไรเดอร์เทคโน และบอสหลักคือ **Venom Mantis** จากไฟล์ต้นฉบับ `03-venom-mantis-3x3.png` ของหน้าเลือกวิชา ห้ามเปลี่ยนบอสเป็นตัวอื่น

เปิด `Techno-P3-Offline.html` เพื่อทดลองได้ทันที หรือใช้ localhost โดยไม่ต้องเชื่อมบัญชีใด โหมดผู้เข้าชมไม่บันทึกคะแนน โหมด Rider Code ในต้นแบบใช้รายชื่อสมมติ 01–20 และ PIN 1234; คะแนนเก็บแยกตามปีและรหัสในเบราว์เซอร์เครื่องนั้น รหัสครูต้นแบบ 2468 มีไว้ลองหน้าจอเท่านั้น ไม่ใช่รหัสระบบจริง

## โครงเรียนที่นำไปใช้จริง

มี 9 บท บทละ 14 ด่าน รวม 126 ด่าน และคะแนนเต็มบทละ 100 คะแนน ลำดับคือ เปิดเรื่อง → ก่อนเรียน → เนื้อหาแรก → ตัวอย่างต่างโจทย์ → ภารกิจ A → เกมฝึกครั้ง 1 → เนื้อหาที่สอง → สนามทดลอง → ภารกิจ B → เกมฝึกครั้ง 2 → ชิ้นงาน → หลังเรียน → ดวลบอส → สรุปผล นักเรียนแตะเลขด่าน 1–14 เพื่อทบทวนหรือเลือกด่านได้ แต่ปุ่มเล่นต่อพาไปด่านที่ยังไม่ผ่านตามลำดับ

| บท | เนื้อหา | ภารกิจและเกมที่ใช้จริง |
|---|---|---|
| 1 | เหตุผล เงื่อนไข และลำดับ | ตัดสินใจจากหลักฐาน จัดลำดับแผนสองสถานการณ์ |
| 2 | โปรแกรมเงื่อนไข ตรวจข้อผิดพลาด | สนาม 5×5 แบบ Code.org วางบัตร เดินทีละขั้น ทดสอบ 2 กรณี |
| 3 | ความปลอดภัยดิจิทัล | ตรวจข้อความ ข้อมูลส่วนตัว สิทธิ์อุปกรณ์ และการขอความช่วยเหลือ |
| 4 | ค้นหาและประมวลข้อมูล | จำลองเลือกคำค้น ผลลัพธ์ และข้อมูลที่นำไปใช้ |
| 5 | สื่อนำเสนอ | จัดองค์ประกอบสไลด์ ตรวจตัวเลขและข้อสรุป |
| 6 | อัลกอริทึมแก้ปัญหา | เกมจัดของขึ้นยานภายใต้ความจุและจำนวนเที่ยว |
| 7 | โปรแกรมทำซ้ำ | สนาม 5×5 แบบ Code.org ใช้ REPEAT เก็บผลึกและแก้ลูป |
| 8 | ค้นหาความรู้และมารยาท | คัดผลค้นหา ตรวจคำสุภาพและข้อมูลส่วนตัว |
| 9 | เทคโนโลยี AR | ตรวจชั้นภาพซ้อนกับหลักฐานจริงและความปลอดภัย |

บท 2 และ 7 ใช้บัตรคำสั่งตามระดับ ป.3 ในคู่มือ สสวท. โดยเฉพาะบท 7 มีแนว Code.org ในคู่มือ ป.3 **ไม่มี Scratch ในหลักสูตรคู่มือ ป.3** จึงไม่ใส่บล็อก Scratch ปลอม บทอื่นมีเกมแทรกห้าวิธีเล่นที่แตกต่างกัน ภารกิจ A, B และบอสใช้สถานการณ์คนละชุด; แบบทดสอบก่อนและหลังเรียนใช้โจทย์คู่ขนานคนละสถานการณ์

คะแนนต่อบท: ภารกิจ A 15, เกม 1 5, ภารกิจ B 15, เกม 2 5, ชิ้นงาน 20, หลังเรียน 20, บอส 20 คะแนน รวม 100 คะแนน แบบทดสอบก่อนเรียนเก็บ 0–20 เพื่อแสดงพัฒนาการแต่ไม่คิดรวม 100 คะแนน ก่อนเรียนไม่เฉลยระหว่างทำและใช้คะแนนครั้งแรกเป็นฐานเปรียบเทียบ แม้กลับมาฝึกซ้ำ หลังเรียนเล่นซ้ำเพื่อเพิ่มคะแนนได้ คะแนนชิ้นงาน 15 เมื่อส่งคำอธิบาย และเพิ่มเป็น 20 เมื่อครูยืนยันใน GAS

## แผนและเนื้อหา

`../แผนพัฒนาเว็บ_ป3_9บท_ส่งต่อAI/00_อ่านก่อน_AI.md` คือแผนละเอียดของทั้ง 9 บท `course-plan.json` คือข้อมูลเชิงโครงสร้างที่เว็บใช้ `page-manifest.csv` บอกหน้าภายในทุกด่าน `p3_data.py` เป็นแหล่งข้อความเนื้อหาและจุดประสงค์หลัก ต้องแก้ข้อมูลที่นั่นแล้วรัน `build_plan.py` และ `../ต้นแบบเว็บ_ป3/build.py` ตามลำดับ เพื่อไม่ให้ JSON กับข้อความต้นทางต่างกัน

ตัวเลข 324 หน้าในแผนเป็น **คำอธิบายหน้าที่วางไว้สำหรับพัฒนาต่อ** ไม่ใช่จำนวนหน้าจอที่เปิดแยกครบแล้วในต้นแบบปัจจุบัน ระบบเล่นได้ครบ 126 ด่าน; ด่านเปิดเรื่อง บทเรียน และตัวอย่างแสดงเนื้อหา 2 หน้า ส่วนข้อสอบมี 5 ข้อกับผลสรุป ขณะที่ภารกิจ เกม ชิ้นงาน และบอสเปิดเป็นหน้าจอเดียวที่โต้ตอบได้ การออกแบบเกมเชิงลึกบางข้อในแผน เช่น ชุดทดสอบบอส 4 สนาม และโบนัสเวลา ยังเป็นแนวขยาย ไม่ควรบอกว่ามีในโค้ดแล้ว

โค้ด `p3-activity.js` เก็บชุดข้อสอบและโจทย์ภารกิจ, `p3-grid.js` เก็บสนามเดินตามช่อง, `p3-special.js` เก็บเกมแทรก, `p3-app.js` เป็นหน้าจอและการให้คะแนน, `p3-gas.js` เป็นสะพานไป GAS, `p3.css` เป็นธีมและหน้าจอ ภาพใช้งานเว็บอยู่ใน `assets/`; รายละเอียดต้นฉบับอยู่ใน `ASSET_USAGE.md`

## GAS และ Google Sheets

โฟลเดอร์ `../gas-p3/` เป็นแพ็กเกจแยกของ ป.3 ยังไม่ได้เผยแพร่ เพราะยังไม่มี Script ID ของ ป.3 โค้ดเซิร์ฟเวอร์ `Code.gs` จะสร้าง Google Sheet และโฟลเดอร์ภาพใหม่เมื่อเรียก `setupP3(username,password)` ครั้งแรก โดยให้ผู้ติดตั้งกำหนดบัญชีผู้ดูแลและรหัสส่วนตัวอย่างน้อย 12 ตัวใน Apps Script เอง ไม่มีรหัสครูจริงฝังในโค้ด

ชีตที่สร้าง: Settings, Years, Students, Staff, States, Progress, StageScores, ProductReview, Audit ข้อมูลนักเรียนอยู่ตามปีการศึกษา แอดมินตั้งปีที่แสดงและเพิ่มบัญชีครูได้ ครูจัดรายชื่อ เปิด/ปิดผู้เรียน ดูคะแนนรายบท อ่านเหตุผลที่เขียนในบทเรียน อ่านชิ้นงาน และยืนยันชิ้นงาน เซิร์ฟเวอร์ตรวจ PIN และเก็บรหัสผ่านเป็นแฮชพร้อมเกลือ โหมดผู้เข้าชมไม่ส่งผลเรียน

เมื่อจะลงระบบจริง ให้รัน `python ../gas-p3/build_gas.py` แล้วนำ `Code.gs`, `appsscript.json`, `Index.html` และ `Chunk*.html` ไปยังโปรเจ็กต์ Apps Script **ใหม่สำหรับ ป.3** จากนั้นรัน setupP3 ก่อน Deploy เป็น Web App; ฝัง URL เว็บแอปใน Google Sites ของ ป.3 ภาพทั้งหมดถูกฝังในหน้าเว็บ GAS แล้ว ส่วนโฟลเดอร์ภาพที่สร้างไว้ข้างชีตใช้เก็บต้นฉบับหรือชิ้นงานที่เพิ่มภายหลัง หากต้องการอัปโหลดภาพชิ้นงานจากผู้เรียนในอนาคต ต้องออกแบบสิทธิ์และขนาดไฟล์ก่อนเพิ่ม endpoint

## ตรวจงาน
