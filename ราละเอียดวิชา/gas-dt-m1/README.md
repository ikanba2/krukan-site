## อัปเดตโค้ด (หลังมี deployment แล้ว)
`python build_gas.py` → `clasp push -f` → `clasp create-version` → `clasp update-deployment <deploymentId> --versionNumber N`
(ไฟล์ที่ push กำหนดใน `.claspignore` · ถ้า clasp บ่นว่า "Project file already exists" ให้สั่งแบบ `clasp -P <โฟลเดอร์นี้> -I <โฟลเดอร์นี้> push -f` เพราะมี `.clasp.json` เก่าค้างอยู่ที่โฟลเดอร์ผู้ใช้)
ไฟล์ Chunk/Index สร้างใหม่ทุกครั้ง ไม่ commit

## ให้ AI (Gemini) ร่างข้อเสนอแนะให้ครู (ไม่บังคับ)

ฟังก์ชัน `aiDraftReview` ใน `Code.gs` ให้ครูกดปุ่ม "✨ ให้ AI ร่างคะแนนและข้อเสนอแนะ" ในหน้าตรวจงาน AI เป็นผู้ร่างเท่านั้น ครูตรวจแก้และกดบันทึกเอง และนักเรียนเห็นหมายเหตุว่ามี AI ช่วยร่าง

ตั้งค่า (ทำใน Apps Script → Project Settings → Script Properties):
1. `GEMINI_API_KEY` = คีย์จาก https://aistudio.google.com/apikey (**ห้ามใส่ในโค้ด หน้าเว็บ หรือแชท**)
2. `GEMINI_MODEL` (ไม่บังคับ ค่าเริ่มต้น `gemini-flash-latest` · ถ้าชื่อรุ่นถูกเลิกใช้ (404) ระบบเลือกรุ่น flash ใหม่สุดที่คีย์ใช้ได้ให้เองและจำไว้ใน `DT_AI_MODEL_AUTO`)
3. `DT_AI_DAILY` (ไม่บังคับ โควตาเรียกต่อวันของทั้งระบบ ค่าเริ่มต้น 150)

ข้อกำหนดที่ทำไว้: เรียกได้เฉพาะครูที่เข้าระบบแล้วกับงานนักเรียนที่ส่งเข้าระบบ (ผู้เยี่ยมชมไม่มีงานในระบบ) · ส่งเฉพาะข้อความงานตามหัวข้อ ไม่ส่งชื่อ เลขที่ ห้อง · คำสั่งระบบกันการสั่งแฝงในงานนักเรียน · งานเดิมขอซ้ำได้ทุก 15 วินาที · คีย์ส่งทางหัวข้อความ ไม่อยู่ใน URL · เก็บบันทึกว่าใครขอร่างงานไหนใน AuditLog (ไม่เก็บข้อความงาน)

**ยังไม่เคยเรียก Gemini จริง** ทดสอบกับตัวจำลองเท่านั้น (test_code.js 42 รายการ) ในเวอร์ชันออฟไลน์ `gas-sim.js` ปุ่มนี้ตอบข้อความตัวอย่างที่ติดป้ายว่า "ไม่ได้มาจาก AI จริง" ก่อนใช้จริงควรลองกับงานตัวอย่าง ตรวจภาษาไทยของร่างและเงื่อนไขข้อมูลของ Gemini ระดับฟรี (ข้อมูลอาจถูกนำไปปรับปรุงผลิตภัณฑ์ของ Google)
