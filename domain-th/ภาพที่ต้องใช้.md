# ภาพประกอบหน้า “รู้จัก .th และ .ไทย”

ไฟล์ภาพชุดนี้สร้างใหม่เพื่อใช้กับ `Domain-Th-Thai.html` ตามคำขอวันที่ 19 ตุลาคม 2569

## คุณสมบัติร่วม

- ภาพแนวนอน 16:9 ขนาด 1600×900 พิกเซล บันทึกเป็น WebP
- ภาพประกอบแนวคอมิกสีสด ขอบเส้นชัด ให้เข้ากับหน้าเว็บ
- ข้อความที่เป็นส่วนหนึ่งของภาพอยู่ในภาพที่สร้างแล้ว ไม่วางข้อความทับด้วยโค้ด
- ใช้ Cyber Rider Techno ตามภาพอ้างอิง เมื่อภาพนั้นมีตัวละคร
- แต่ละภาพต้องสื่อเนื้อหาตามหัวข้อของตัวเอง ไม่ใช้ภาพซ้ำ

## รายการภาพ

| ไฟล์ | ตำแหน่ง/เนื้อหา | สิ่งที่สื่อในภาพ |
|---|---|---|
| `domain-th-01-hero.webp` | ภาพเปิดหน้า | เทคโนกับโลกดิจิทัล ข้อความ “รู้จัก .th และ .ไทย” และ “โดเมนของประเทศไทย” |
| `domain-th-02-address-bar.webp` | ส่วนประกอบที่อยู่เว็บ | แยกป้าย 5 ส่วนให้ชัด: แม่กุญแจ=เข้ารหัส, ลูกโลก=บริการเว็บไซต์, บ้าน=ชื่อเว็บ, บุคคล=ประเภทผู้จดทะเบียน, ธง=ประเทศไทย พร้อมเทคโนชี้อธิบาย |
| `domain-th-03-detective.webp` | ตรวจสอบก่อนเชื่อ | เทคโนใช้แว่นขยายดูเว็บ พร้อมแนวทางอ่านชื่อ ดูแม่กุญแจ เทียบเจ้าของ และค้นข้อมูล |
| `domain-th-04-fake-vs-real.webp` | เปรียบเทียบเว็บปลอมกับเว็บจริง | ฝั่งเว็บปลอมมีเบ็ด/มัลแวร์ ฝั่งเว็บจริงมีโล่และกุญแจ เทคโนหยุดภัย |
| `domain-th-05-thai-keyboard.webp` | พิมพ์ชื่อเว็บภาษาไทย | เทคโนพิมพ์คีย์บอร์ด ตัวอักษร ก ข ค ง และแถบที่อยู่เว็บ |
| `domain-th-06-victory.webp` | หน้าผลเกมเมื่อผ่าน | เทคโนฉลองพร้อมถ้วยรางวัลรูปโลก ข้อความ “ภารกิจสำเร็จ!” |
| `domain-th-07-family-school.webp` | ประโยชน์ของชื่อเว็บไทย | ผู้ปกครองและเด็กใช้แล็ปท็อป มีเว็บโรงเรียนและชื่อครูการ.ไทย |
| `domain-th-08-vs-com.webp` | เปรียบเทียบ .th/.ไทย กับ .com | โดเมนประเทศไทยเทียบกับโดเมนที่ใช้ได้ทั่วโลก |

## การเรียกใช้

หน้าเว็บค้นภาพในโฟลเดอร์ `domain-th/` โดยใช้ชื่อช่องภาพตรงกับชื่อไฟล์ เช่น `domain-th-01-hero.webp` จึงไม่ต้องฝังภาพเป็น Base64 หรือเขียนข้อความทับลงภาพด้วยโค้ด ช่องเปรียบเทียบ `.th/.ไทย` กับ `.com` เพิ่มไว้ในส่วนที่ 2 ของ `tools/build-domain-page.py` แล้ว

ก่อนนำขึ้น Google Sites ให้อัปโหลดไฟล์ WebP ทั้งหมดขึ้น Drive และแทนที่พาธภาพในหน้าเว็บด้วย URL หรือรหัสไฟล์ Drive ที่แชร์ใช้งานได้

หมายเหตุภาพที่ 2: การ์ดอธิบายป้าย 5 ใบใต้ภาพ ตัดไอคอนมาจากไฟล์ `domain-th-02-address-bar.webp` ด้วย CSS (ไอคอนในการ์ดอธิบาย) จึงต้องเปลี่ยนพาธ `url(domain-th/domain-th-02-address-bar.webp?v=…)` ในสไตล์ `.addr-key .ico` ให้ตรงกับที่ใหม่ด้วยเมื่อย้ายภาพไป Drive
