# บันทึกการตรวจข้อเท็จจริง หน้า "รู้จัก .th และ .ไทย"

ตรวจเมื่อ 19 ตุลาคม 2569 (ค.ศ. 2026) กับเอกสารทางการ เก็บไว้เป็นหลักฐานประกอบเกณฑ์ข้อ 1.6 (ความถูกต้องของเนื้อหา) และใช้ตรวจซ้ำเมื่อเงื่อนไขของ THNIC เปลี่ยน

## ผลตรวจรายข้อ
| ข้อความในหน้าเว็บ | ผล | หลักฐาน/สิ่งที่แก้ |

| .ไทย เป็น ccTLD เขียนด้วยอักษรไทย รหัส xn--o3cw4h | ถูก | IANA (ไทย / Thai script) |
| .com เป็นโดเมนทั่วไป (gTLD) ใช้ทั่วโลก | ถูก | IANA |

| ชื่อ .th ต้องยืนยันตัวตนผู้ขอ | ถูก | THNIC: ชื่อโดเมนทุกชื่อได้รับการตรวจสอบยืนยันตัวตนก่อนการใช้งาน |

| .co.th = ธุรกิจ | ถูก **เพิ่มเงื่อนไข** | นิติบุคคลที่จดกับกรมพัฒนาธุรกิจการค้า, ผู้จดภาษีมูลค่าเพิ่ม, รัฐวิสาหกิจ, เจ้าของเครื่องหมายการค้าที่จดกับกรมทรัพย์สินทางปัญญา, ต่างประเทศผ่านตัวแทน |

## ข้อควรรู้
- เอกสารนโยบายเป็นฉบับปรับปรุง พฤษภาคม 2563 ซึ่งยังเผยแพร่อยู่บนเว็บ THNIC ในปี 2569 และมีแนวปฏิบัติ SLD ปี 2569 ที่เกี่ยวข้อง หากมีฉบับใหม่ควรตรวจซ้ำ
- ตัวย่อ ac = academic, co = company/commercial, go = government, or = organization, mi = military, net = network เป็นความหมายที่ใช้กันทั่วไป นโยบายอธิบายประเภทเป็นข้อความ ไม่ได้ขยายตัวย่อไว้ จึงเขียนในหน้าเว็บเป็นคำช่วยจำเท่านั้น
- ข้อความ "ตรวจข้อมูลโดเมนผ่าน WHOIS ของ THNIC" ยืนยันแล้วว่ามีบริการ WHOIS (`whois.thnic.co.th`) แต่ยังไม่ได้ตรวจว่าแสดงข้อมูลผู้จดทะเบียนละเอียดแค่ไหน จึงเขียนในหน้าเว็บว่า "ข้อมูลที่แสดงขึ้นกับนโยบายของผู้ดูแล"
