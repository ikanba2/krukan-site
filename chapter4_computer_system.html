บทที่ 4: หลักการทำงานของระบบคอมพิวเตอร์

เรียนรู้ส่วนประกอบพื้นฐานและกลไกการทำงานที่ขับเคลื่อนโลกดิจิทัล ตั้งแต่ฮาร์ดแวร์ที่จับต้องได้ไปจนถึงซอฟต์แวร์ที่ชาญฉลาด

สถาปัตยกรรมระบบ

โครงสร้างระบบคอมพิวเตอร์

CPU, RAM, Storage และการรับส่งข้อมูลผ่าน System Bus

CPU ประมวลผล RAM หน่วยความจำ Storage ที่เก็บถาวร Bus ระบบส่งข้อมูล

วิวัฒนาการของคอมพิวเตอร์ 4 ยุค

เส้นเวลาวิวัฒนาการ: จากคอมพิวเตอร์หลอดสุญญากาศขนาดเท่าห้อง สู่ไมโครโปรเซสเซอร์ในสมาร์ทโฟน

1940s - 1950s: ยุคหลอดสุญญากาศ (Vacuum Tube)

คอมพิวเตอร์มีขนาดใหญ่เท่าห้อง ใช้พลังงานไฟฟ้าสูงมาก เกิดความร้อนสะสมสูง และต้องซ่อมแซมหลอดที่ขาดบ่อยครั้ง เช่น เครื่อง ENIAC

1960s: ยุคทรานซิสเตอร์ (Transistor)

การนำทรานซิสเตอร์มาใช้แทนหลอดสุญญากาศ ทำให้ตัวเครื่องมีขนาดเล็กลงอย่างก้าวกระโดด กินไฟน้อยลง ทนทานขึ้น และเริ่มนำมาใช้ในเชิงพาณิชย์และธุรกิจ

1970s: ยุควงจรรวม (Integrated Circuit - IC)

การนำทรานซิสเตอร์หลายพันตัวมารวมไว้บนแผ่นซิลิคอนชิปขนาดเล็ก เป็นจุดกำเนิดของคอมพิวเตอร์ส่วนบุคคล (Personal Computer - PC)

1980s - ปัจจุบัน: ยุคไมโครโปรเซสเซอร์ (Microprocessor & AI)

การรวมวงจรทั้งหมดลงบนชิป CPU ชิ้นเดียว ทำให้เกิดคอมพิวเตอร์พกพา แล็ปท็อป สมาร์ทโฟน และอุปกรณ์ IoT ที่ทำงานร่วมกับปัญญาประดิษฐ์

1

องค์ประกอบของระบบคอมพิวเตอร์

ฮาร์ดแวร์ (Hardware)

ส่วนประกอบทางกายภาพที่จับต้องได้ เช่น CPU, RAM, จอภาพ, คีย์บอร์ด, เมาส์, และฮาร์ดดิสก์

ซอฟต์แวร์ (Software)

ชุดคำสั่งหรือโปรแกรมที่ควบคุมการทำงานของฮาร์ดแวร์ แบ่งเป็นซอฟต์แวร์ระบบ (OS) และซอฟต์แวร์ประยุกต์

บุคลากร (Peopleware)

บุคคลผู้สั่งการและใช้งานระบบ เช่น ผู้ใช้งานทั่วไป, โปรแกรมเมอร์, ผู้ดูแลระบบ, และนักวิเคราะห์ระบบ

เจาะลึกส่วนประกอบฮาร์ดแวร์ (Hardware Components)

💡 สรุปเปรียบเทียบ: CPU (สมองคิด) • RAM (โต๊ะทำงานชั่วคราว) • Storage (ตู้เก็บเอกสารถาวร)
หน่วยประมวลผลกลาง (CPU)

เปรียบเสมือน "สมอง" ทำหน้าที่คำนวณ คิดวิเคราะห์ และประมวลผลคำสั่งทั้งหมดในคอมพิวเตอร์

หน่วยความจำหลัก (RAM)

เปรียบเสมือน "โต๊ะทำงาน" พักข้อมูลที่กำลังใช้งาน ยิ่งมีมากยิ่งเปิดหลายโปรแกรมพร้อมกันได้ลื่นไหล ข้อมูลหายเมื่อปิดเครื่อง

หน่วยจัดเก็บข้อมูล (Storage)

เปรียบเสมือน "ตู้เก็บเอกสาร" บันทึกไฟล์และโปรแกรมถาวร ข้อมูลไม่สูญหายเมื่อปิดเครื่อง เช่น SSD และ Hard Disk

หน่วยรับเข้า (Input Devices)

อุปกรณ์ป้อนคำสั่งและข้อมูล เช่น คีย์บอร์ด, เมาส์, สแกนเนอร์, ไมโครโฟน, ทัชสกรีน

หน่วยส่งออก (Output Devices)

อุปกรณ์แสดงผลลัพธ์ที่ประมวลผลแล้วสู่ผู้ใช้ เช่น จอภาพ (Monitor), เครื่องพิมพ์ (Printer), ลำโพง (Speaker)

ประเภทของซอฟต์แวร์

ซอฟต์แวร์ระบบ (System Software)

เป็นโปรแกรมที่ทำหน้าที่จัดการและควบคุมฮาร์ดแวร์ทั้งหมด เปรียบเสมือน "ผู้จัดการ" ของคอมพิวเตอร์ เพื่อให้ซอฟต์แวร์ประยุกต์ทำงานได้

Windows macOS Linux Android / iOS
ซอฟต์แวร์ประยุกต์ (Application Software)

เป็นโปรแกรมที่สร้างขึ้นเพื่อตอบสนองการทำงานเฉพาะอย่างตามความต้องการของผู้ใช้ เปรียบเสมือน "เครื่องมือช่าง" ที่เราหยิบใช้

MS Word Google Docs Photoshop Web Browser

หลักการทำงานของระบบคอมพิวเตอร์

คอมพิวเตอร์ "เข้าใจ" ข้อมูลได้อย่างไร?

คอมพิวเตอร์เป็นอุปกรณ์อิเล็กทรอนิกส์ เข้าใจเพียง 2 สถานะคือ "เปิดไฟ (1)" และ "ปิดไฟ (0)" ข้อมูลทุกชนิดไม่ว่าจะเป็นข้อความ รูปภาพ เพลง หรือวิดีโอ จึงต้องถูกแปลงเป็น "เลขฐานสอง (Binary Code)" ก่อนประมวลผล

0 = ปิด (OFF)

➔
สวิตช์ไฟฟ้าขนาดจิ๋วนับพันล้านตัวในชิปประมวลผล (Transistors) เปิด-ปิด ด้วยความถี่สูง
➔

1 = เปิด (ON)

ทดลองแปลงข้อความเป็นเลขฐานสอง (Binary)
ผลลัพธ์เลขฐานสองจะแสดงที่นี่

วงรอบเครื่องจักร (Machine Cycle): หัวใจของ CPU

การทำงานภายในซีพียูจะวนซ้ำ 3 ขั้นตอนหลักนี้อย่างต่อเนื่องหลายพันล้านรอบต่อวินาที (Clock Speed)

⚡ วงรอบการประมวลผล: 1. Fetch (นำคำสั่ง) ➔ 2. Decode (ถอดรหัส) ➔ 3. Execute (คำนวณ) แล้ววนซ้ำ
1
การนำคำสั่ง (Fetch)

หน่วยควบคุม (CU) ไป "หยิบ" คำสั่งถัดไปจากหน่วยความจำ RAM มาเตรียมพร้อมไว้ในรีจิสเตอร์

2
การถอดรหัส (Decode)

CU "แปลความหมาย" ของคำสั่งนั้นว่าสั่งให้ทำอะไร เช่น คำนวณเลข, โอนย้ายข้อมูล, หรือเปรียบเทียบค่า

3
การทำงาน (Execute)

หน่วย ALU "ลงมือคำนวณและประมวลผล" ตามที่ถอดรหัสไว้ แล้วส่งผลลัพธ์ไปบันทึกลงใน RAM
