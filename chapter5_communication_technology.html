วิทยาการคำนวณ ม.2 • บทที่ 5

เทคโนโลยีการสื่อสาร

เรียนรู้ว่าข้อมูลเดินทางจากอุปกรณ์หนึ่งไปยังอีกอุปกรณ์หนึ่งได้อย่างไร เครือข่ายคอมพิวเตอร์และอินเทอร์เน็ตทำงานอย่างไร และเราควรเลือกใช้เทคโนโลยีการสื่อสารแบบใดให้เหมาะสมกับสถานการณ์จริง

เวลาเรียนแนะนำ 5 ชั่วโมง ตัวชี้วัด ว 4.2 ม.2/3 เน้นความเข้าใจ + การประยุกต์ใช้
ภาพรวมสถาปัตยกรรม: การสื่อสารข้อมูล องค์ประกอบ สื่อกลาง อุปกรณ์ และการเชื่อมต่อเครือข่ายระดับโลก ภาพประกอบทางการศึกษา
สารบัญ: จุดประสงค์ ความหมาย องค์ประกอบ เครือข่าย อินเทอร์เน็ต สื่อกลาง อุปกรณ์เครือข่าย โพรโทคอล การเลือกใช้ กิจกรรม สรุป แบบทดสอบ

1. จุดประสงค์การเรียนรู้

เมื่อเรียนบทนี้จบ นักเรียนควรสามารถ

1) อธิบายการสื่อสารข้อมูล บอกองค์ประกอบของการสื่อสารข้อมูลได้ครบถ้วนทั้ง 5 ส่วน
2) อธิบายเครือข่าย แยกความแตกต่างของ LAN, WAN และอินเทอร์เน็ตได้อย่างถูกต้อง
3) รู้จักสื่อกลาง เปรียบเทียบข้อดีและข้อจำกัดของการเชื่อมต่อแบบมีสายและไร้สายได้
4) เลือกใช้เทคโนโลยี เลือกวิธีสื่อสารให้เหมาะกับความเร็ว ระยะทาง ค่าใช้จ่าย และความปลอดภัย

2. เทคโนโลยีการสื่อสารคืออะไร?

เทคโนโลยีการสื่อสาร (Communication Technology) คือ เทคโนโลยีที่ช่วยให้มนุษย์หรืออุปกรณ์สามารถ ส่ง รับ แลกเปลี่ยน หรือแบ่งปันข้อมูลระหว่างกันได้ เช่น ข้อความ เสียง ภาพ วิดีโอ เอกสาร หรือข้อมูลจากเซนเซอร์ตรวจวัดต่าง ๆ

💡 ลองนึกภาพ: เมื่อนักเรียนส่งรูปภาพจากโทรศัพท์ให้เพื่อน รูปนั้นไม่ได้ “ลอย” ข้ามอากาศไปเองทันที แต่จะถูกแบ่งเป็นแพ็กเก็ตข้อมูลดิจิทัล (0 และ 1) ส่งผ่านคลื่นวิทยุหรือสายสัญญาณ ข้ามเครือข่ายอินเทอร์เน็ต แล้วจึงประกอบกลับเป็นรูปภาพบนหน้าจอของเพื่อน

ตัวอย่างในชีวิตประจำวัน

📱 ส่งข้อความผ่าน LINE: คุยแชต ส่งสติกเกอร์กับเพื่อน
🎥 เรียนออนไลน์ Google Meet: ถ่ายทอดภาพและเสียงแบบสด
📧 ส่งอีเมลพร้อมแนบงาน: รับส่งไฟล์เอกสารทางการ
🎮 เล่นเกมออนไลน์: แลกเปลี่ยนสถานะเกมแบบเรียลไทม์
☁️ Google Drive / Cloud: จัดเก็บและสำรองข้อมูลบนคลาวด์
🏠 กล้องวงจรปิด IoT: ดูภาพสดผ่านสมาร์ตโฟนได้จากทุกที่

3. องค์ประกอบของการสื่อสารข้อมูล

การสื่อสารข้อมูลโดยทั่วไปมีองค์ประกอบสำคัญ 5 ส่วน ที่ต้องทำงานร่วมกันอย่างสมบูรณ์

1. ผู้ส่ง→ 2. ข้อมูล→ 3. สื่อกลาง→ 4. ผู้รับ+ 5. โพรโทคอล (กติกา)
ภาพที่ 5.1: โครงสร้าง 5 องค์ประกอบของการสื่อสารข้อมูล (Sender, Message/Data, Medium, Receiver, Protocol)
องค์ประกอบความหมายและหน้าที่ตัวอย่างในชีวิตประจำวัน
1. ผู้ส่ง (Sender) อุปกรณ์หรือบุคคลที่เริ่มต้นสร้างและส่งข้อมูลออกไป โทรศัพท์ของนักเรียน, คอมพิวเตอร์ต้นทาง, กล้องเว็บแคม
2. ข้อมูล (Message/Data) สิ่งที่ต้องการส่งต่อในรูปแบบสัญญาณดิจิทัล ข้อความแชต, รูปถ่าย, ไฟล์เสียง, วิดีโอคลิป
3. สื่อกลาง (Transmission Medium) เส้นทางหรือช่องทางที่ข้อมูลใช้เดินทางไปยังปลายทาง สาย LAN, ใยแก้วนำแสง (Fiber), คลื่น Wi-Fi, สัญญาณมือถือ
4. ผู้รับ (Receiver) อุปกรณ์หรือบุคคลที่รับข้อมูลและแปลงกลับมาใช้งาน สมาร์ตโฟนของเพื่อน, หน้าจอคอมพิวเตอร์ปลายทาง
5. โพรโทคอล (Protocol) กฎ ข้อกำหนด หรือมาตรฐานที่ทำให้อุปกรณ์สื่อสารกันเข้าใจ TCP/IP, HTTP, HTTPS, Wi-Fi 802.11
กรณีศึกษา: ครูส่งไฟล์ใบงานผ่าน Google Classroom
• ผู้ส่ง: คอมพิวเตอร์ของครูผู้สอน
• ข้อมูล: ไฟล์ PDF ใบงานวิทยาการคำนวณ
• สื่อกลาง: สัญญาณ Wi-Fi โรงเรียน และโครงข่ายใยแก้วนำแสงอินเทอร์เน็ต
• ผู้รับ: โทรศัพท์มือถือหรือแท็บเล็ตของนักเรียน
• โพรโทคอล: HTTPS และ TCP/IP ที่ดูแลการรับส่งไฟล์อย่างปลอดภัยและครบถ้วน

4. เครือข่ายคอมพิวเตอร์

เครือข่ายคอมพิวเตอร์ (Computer Network) คือ การเชื่อมต่อคอมพิวเตอร์หรืออุปกรณ์ดิจิทัล ตั้งแต่ 2 เครื่องขึ้นไปเข้าด้วยกัน เพื่อให้สามารถสื่อสาร แลกเปลี่ยนข้อมูล และแบ่งปันทรัพยากรร่วมกันได้

ประโยชน์ของเครือข่ายคอมพิวเตอร์

  • แชร์ไฟล์และข้อมูล: ส่งไฟล์งานเอกสาร ภาพ วิดีโอได้สะดวกรวดเร็วโดยไม่ต้องใช้ Flash Drive
  • ใช้อุปกรณ์ร่วมกัน (Resource Sharing): เช่น เครื่องพิมพ์ (Printer) เครื่องเดียวสามารถสั่งพิมพ์ได้จากคอมพิวเตอร์ทั้งห้อง
  • สื่อสารได้รวดเร็ว: ประชุมออนไลน์ โทรศัพท์ผ่านเน็ต แชตกลุ่มแบบเรียลไทม์
  • เข้าถึงบริการบนอินเทอร์เน็ต: ค้นหาความรู้ ดูคลิปสารคดี บริการธนาคารออนไลน์
  • จัดเก็บข้อมูลส่วนกลาง: สำรองข้อมูลบน Server หรือ Cloud ปลอดภัยและกู้คืนได้ง่าย
ภาพที่ 5.2: การจำแนกประเภทเครือข่ายคอมพิวเตอร์ตามระยะทางและขอบเขตพื้นที่ (LAN, MAN, WAN, Internet)

ประเภทของเครือข่ายตามพื้นที่

ประเภทชื่อเต็มขอบเขตพื้นที่ตัวอย่างการใช้งาน
LAN Local Area Network พื้นที่ขนาดเล็ก เช่น ห้อง บ้าน อาคาร หรือโรงเรียน (ไม่เกิน 1-2 กม.) เครือข่ายห้องปฏิบัติการคอมพิวเตอร์, Wi-Fi ภายในบ้าน
MAN Metropolitan Area Network พื้นที่ระดับเมืองหรือเทศบาล เชื่อมหลายอาคารเข้าด้วยกัน เครือข่ายกล้องวงจรปิดเทศบาล, เครือข่ายเคเบิลทีวีเมือง
WAN Wide Area Network พื้นที่กว้าง เชื่อมระดับจังหวัด ประเทศ หรือข้ามทวีป เครือข่ายตู้ ATM และสาขาของธนาคารทั่วประเทศ
Internet International Network เครือข่ายขนาดใหญ่ระดับโลกที่เชื่อม LAN และ WAN นับล้านเข้าด้วยกัน เว็บไซต์ระดับโลก YouTube, Google, Wikipedia, ระบบคลาวด์
💡 สรุปจำง่าย: LAN = เครือข่ายใกล้ (บ้าน/โรงเรียน) • WAN = เครือข่ายไกล (ข้ามจังหวัด/ประเทศ) • Internet = เครือข่ายของเครือข่ายทั่วโลก

5. อินเทอร์เน็ตทำงานอย่างไรแบบเข้าใจง่าย

เมื่อเราเปิดเว็บไซต์ เช่น เว็บไซต์โรงเรียน อุปกรณ์ของเราจะส่งคำขอ (Request) ผ่านเครือข่าย ไปยังเครื่องคอมพิวเตอร์แม่ข่ายที่ให้บริการเว็บไซต์ เรียกว่า เซิร์ฟเวอร์ (Server) จากนั้นเซิร์ฟเวอร์จะประมวลผลแล้วส่งข้อมูล (Response) กลับมาแสดงผลบนหน้าจอของเรา

โทรศัพท์ / คอมพิวเตอร์ (Client) → เราเตอร์ (Router) → ISP (ผู้ให้บริการอินเทอร์เน็ต) → Server (เครื่องแม่ข่าย) → ส่งข้อมูลกลับมาแสดงผล

คำศัพท์สำคัญที่ควรรู้

Client (ไคลเอนต์) อุปกรณ์ของผู้ใช้งานที่ทำหน้าที่ส่งคำขอรับบริการ เช่น คอมพิวเตอร์ โทรศัพท์มือถือ หรือแท็บเล็ต
Server (เซิร์ฟเวอร์) คอมพิวเตอร์สมรรถนะสูงที่เปิดให้บริการตลอด 24 ชั่วโมง เช่น เว็บเซิร์ฟเวอร์ เซิร์ฟเวอร์เกม หรือคลาวด์
IP Address หมายเลขประจำเครื่องในระบบเครือข่าย เปรียบเสมือน “บ้านเลขที่” บนโลกดิจิทัล เช่น 192.168.1.1
Domain Name (ชื่อโดเมน) ชื่อที่มนุษย์อ่านและจำได้ง่าย ใช้แทนหมายเลข IP Address เช่น www.google.com, www.moe.go.th

6. สื่อกลางในการสื่อสารข้อมูล

สื่อกลางเป็นตัวกลางนำพาข้อมูลจากผู้ส่งไปยังผู้รับ แบ่งออกเป็น 2 ประเภทใหญ่ ได้แก่ แบบมีสาย และแบบไร้สาย

ภาพที่ 5.3: เปรียบเทียบสื่อกลางส่งข้อมูล: แบบมีสาย (สายคู่บิดเกลียว LAN & ใยแก้วนำแสง Fiber Optic) vs แบบไร้สาย (Wi-Fi, Bluetooth, 4G/5G, ดาวเทียม)

6.1 แบบมีสาย (Guided Media)

ชนิดของสายจุดเด่นข้อจำกัดการใช้งานที่เหมาะสม
สายคู่บิดเกลียว (Twisted Pair / LAN / UTP) ราคาประหยัด ติดตั้งง่าย ยืดหยุ่น มีหัวต่อ RJ-45 เป็นมาตรฐานสากล ระยะทางจำกัด (ไม่เกิน 100 เมตรต่อช่วง) อาจมีสัญญาณรบกวนจากคลื่นแม่เหล็ก ภายในห้องคอมพิวเตอร์ บ้านพักอาศัย สำนักงาน
สายใยแก้วนำแสง (Fiber Optic) ส่งข้อมูลด้วยแสง เร็วสูงมาก (ระดับ Gbps) ส่งได้ไกลหลายสิบกิโลเมตร ไม่ถูกรบกวนโดยคลื่นวิทยุ สายเปราะหักง่าย ต้นทุนและค่าอุปกรณ์ติดตั้งสูงกว่า ต้องใช้ช่างผู้ชำนาญการ โครงข่ายอินเทอร์เน็ตความเร็วสูงระดับหมู่บ้าน/เมือง โครงข่ายหลักเชื่อมระหว่างตึก

6.2 แบบไร้สาย (Unguided Media)

เทคโนโลยีความถี่ / ระยะโดยทั่วไปจุดเด่นตัวอย่างการใช้งาน
Bluetooth ระยะใกล้ (ประมาณ 10 เมตร) ประหยัดพลังงาน เชื่อมต่อง่าย ไม่ต้องผ่าน Router หูฟังไร้สาย, คีย์บอร์ด/เมาส์ไร้สาย, สมาร์ตวอทช์, AirDrop ระยะใกล้
Wi‑Fi ระยะปานกลาง (ภายในอาคาร 30–100 เมตร) ส่งข้อมูลได้รวดเร็ว ใช้อุปกรณ์หลายเครื่องพร้อมกันได้ โน้ตบุ๊ก สมาร์ตโฟน สมาร์ตทีวี เชื่อมอินเทอร์เน็ตในบ้านและโรงเรียน
เซลลูลาร์ 4G / 5G ครอบคลุมพื้นที่กว้างตามเสาส่งสัญญาณ (หลายกิโลเมตร) ใช้งานได้ทุกที่แม้กำลังเดินทาง ความเร็วสูงมากในระบบ 5G สมาร์ตโฟน แท็บเล็ต รถยนต์อัจฉริยะ การสตรีมมิงนอกสถานที่
ดาวเทียม (Satellite) ระยะทางไกลมาก (ระดับวงโคจรโลก) ครอบคลุมพื้นที่ทุรกันดาร เกาะ หรือกลางทะเลที่สายส่งไปไม่ถึง เรือเดินสมุทร แท่นขุดเจาะน้ำมัน ระบบระบุพิกัด GPS สัญญาณทีวีผ่านดาวเทียม
💡 หลักคิดสำคัญ: ไม่มีเทคโนโลยีใดดีที่สุดในทุกสถานการณ์! การเลือกใช้ต้องพิจารณาความเร็ว ระยะทาง งบประมาณ ความสะดวก และความปลอดภัยร่วมกันอย่างรอบคอบ

7. อุปกรณ์สำคัญในเครือข่าย

อุปกรณ์เครือข่ายทำหน้าที่รับส่ง จัดเส้นทาง และกระจายสัญญาณข้อมูลเพื่อให้การเชื่อมต่อมีเสถียรภาพ

Router (เราเตอร์) อุปกรณ์เชื่อมต่อเครือข่ายต่างชนิดกันเข้าด้วยกัน และเลือกเส้นทางที่เร็วและดีที่สุดให้ข้อมูลเดินทาง เช่น เชื่อมเครือข่ายในบ้านเข้ากับอินเทอร์เน็ต
Switch (สวิตช์) เชื่อมโยงอุปกรณ์คอมพิวเตอร์หลายเครื่องภายในเครือข่าย LAN เดียวกัน โดยส่งข้อมูลไปยังพอร์ตปลายทางที่ถูกต้องโดยตรงอย่างรวดเร็ว
Access Point (AP) ทำหน้าที่กระจายสัญญาณ Wi-Fi เพื่อให้อุปกรณ์ไร้สาย เช่น โทรศัพท์มือถือ โน้ตบุ๊ก เชื่อมต่อเข้าสู่ระบบเครือข่ายสายหลักได้
Modem (โมเด็ม) แปลงสัญญาณดิจิทัลจากคอมพิวเตอร์ให้เข้ากับสัญญาณของสายผู้ให้บริการอินเทอร์เน็ต (เช่น แปลงสัญญาณแสง Fiber เป็นสัญญาณดิจิทัล)
ภาพที่ 5.4: ผังระบบเครือข่ายห้องปฏิบัติการคอมพิวเตอร์โรงเรียน (School Lab Topology: Modem/Fiber → Router → Switch → LAN Workstations & Access Point)

สถานการณ์ตัวอย่าง: การทำงานในห้องคอมพิวเตอร์โรงเรียน

เมื่อโรงเรียนมีคอมพิวเตอร์ 20–30 เครื่อง สัญญาณอินเทอร์เน็ตจะวิ่งผ่านสาย Fiber Optic เข้าสู่ Modem และ Router จากนั้นสาย LAN จะส่งต่อไปยัง Switch เพื่อกระจายสัญญาณผ่านสาย LAN ให้คอมพิวเตอร์ทุกเครื่องในห้อง ขณะเดียวกัน Access Point จะทำหน้าที่กระจายสัญญาณ Wi-Fi ให้นักเรียนสามารถใช้แท็บเล็ตหรือโทรศัพท์ร่วมเรียนรู้ได้อย่างราบรื่น

8. โพรโทคอล: กติกาที่ทำให้อุปกรณ์คุยกันรู้เรื่อง

หากคนสองคนพูดคนละภาษาโดยไม่มีข้อตกลงหรือภาษาล่ามร่วมกัน ย่อมสื่อสารไม่รู้เรื่อง อุปกรณ์คอมพิวเตอร์ที่ผลิตจากต่างยี่ห้อก็เช่นกัน จึงจำเป็นต้องมี โพรโทคอล (Protocol) เป็นข้อตกลงมาตรฐานเดียวกัน

โพรโทคอลหน้าที่แบบเข้าใจง่ายตัวอย่างการใช้งาน
TCP/IP ชุดกติกาหลักของโลกอินเทอร์เน็ต ดูแลการแบ่งแพ็กเก็ต การกำหนดที่อยู่ และการส่งข้อมูลจนถึงปลายทางโดยไม่สูญหาย โครงสร้างพื้นฐานของอินเทอร์เน็ตทั้งหมด
HTTP กติกาในการร้องขอและส่งข้อมูลหน้าเว็บไซต์ (Hypertext Transfer Protocol) ไม่มีการเข้ารหัส เว็บไซต์บทความทั่วไปในอดีต
HTTPS เหมือน HTTP แต่เพิ่มระบบรักษาความปลอดภัยและการเข้ารหัสลับข้อมูล (SSL/TLS) ป้องกันการถูกดักฟัง เว็บไซต์ธนาคาร, หน้า Login, ซื้อของออนไลน์, Facebook, YouTube
ข้อควรระวังด้านความปลอดภัย: เมื่อเข้าใช้งานเว็บไซต์ใดๆ ควรสังเกตสัญลักษณ์ แม่กุญแจสีเขียว หรือตัวย่อ https:// บนแถบที่อยู่เว็บเสมอ โดยเฉพาะอย่างยิ่งเมื่อต้องกรอกชื่อผู้ใช้ รหัสผ่าน หรือข้อมูลบัตรเครดิต เพื่อป้องกันมิจฉาชีพดักจับข้อมูล

9. หลักการเลือกใช้เทคโนโลยีการสื่อสาร

ก่อนเลือกเทคโนโลยีการเชื่อมต่อหรือส่งข้อมูล ควรพิจารณาจาก 6 ปัจจัยหลักต่อไปนี้

⚡ ความเร็ว (Speed)ปริมาณข้อมูลที่ต้องการส่ง เช่น ดูวิดีโอ 4K หรือแชตข้อความธรรมดา
📍 ระยะทาง (Distance)ใกล้ระดับโต๊ะทำงาน ระดับห้อง หรือข้ามจังหวัด
💰 ค่าใช้จ่าย (Cost)งบประมาณในการซื้ออุปกรณ์ ค่าติดตั้ง และค่าบริการรายเดือน
🔒 ความปลอดภัย (Security)ความเสี่ยงต่อการถูกดักฟังหรือโจรกรรมข้อมูลสำคัญ
📶 ความเสถียร (Reliability)ความต่อเนื่องของสัญญาณ ไม่สะดุดแม้ฝนตกหรือมีสิ่งกีดขวาง
🧳 ความสะดวก (Portability)ความคล่องตัวในการพกพาและใช้งานขณะเดินทาง

ลองวิเคราะห์สถานการณ์จริง

สถานการณ์เทคโนโลยีที่เหมาะสมที่สุดเหตุผลสนับสนุน
ห้องปฏิบัติการคอมพิวเตอร์ 30 เครื่อง สาย LAN (UTP) สัญญาณเสถียร ความเร็วคงที่ ไม่ถูกรบกวน เหมาะกับเครื่องตั้งโต๊ะประจำที่
นักเรียนใช้งานแท็บเล็ตในห้องเรียน Wi-Fi (Access Point) เคลื่อนย้ายสะดวก รองรับการเชื่อมต่อพร้อมกันหลายอุปกรณ์โดยไม่มีสายเกะกะ
เชื่อมต่อหูฟังไร้สายกับสมาร์ตโฟน Bluetooth ระยะใกล้มาก ใช้พลังงานต่ำ จับคู่รวดเร็ว ไม่ต้องพึ่งพาเครือข่ายอินเทอร์เน็ต
ดูแผนที่นำทาง GPS ระหว่างเดินทางต่างจังหวัด เซลลูลาร์ 4G / 5G มีเสาสัญญาณครอบคลุมพื้นที่กว้าง เชื่อมต่อได้ต่อเนื่องแม้รถกำลังเคลื่อนที่

10. กิจกรรมระหว่างเรียน

กิจกรรมที่ 1: ตามรอยข้อมูล (Trace the Data)

ให้นักเรียนเลือกสถานการณ์ในชีวิตประจำวัน 1 อย่าง เช่น “การส่งสติกเกอร์ LINE หาคุณแม่” หรือ “การดูคลิปบน TikTok” แล้วเขียนแจกแจงเส้นทางข้อมูลตามองค์ประกอบ 5 ส่วนให้ถูกต้อง:

โครงสร้างคำตอบ:
1. ผู้ส่ง: ..............................................................
2. ข้อมูล: ..............................................................
3. สื่อกลาง: ..............................................................
4. ผู้รับ: ..............................................................
5. โพรโทคอล: ..............................................................

กิจกรรมที่ 2: เลือกเครือข่ายให้เหมาะสม

แบ่งกลุ่มนักเรียน 3–4 คน ร่วมกันวิเคราะห์และเสนอวิธีแก้ปัญหาใน 4 สถานการณ์ต่อไปนี้

  1. โรงเรียนต้องการต่อระบบเครือข่ายให้กับห้องปฏิบัติการวิทยาศาสตร์ใหม่ 25 เครื่อง
  2. คุณครูต้องการจัดกิจกรรมให้นักเรียนใช้แท็บเล็ตทำแบบทดสอบพร้อมกัน 40 คนในห้องเรียน
  3. นักเรียนต้องการตัดต่อและส่งไฟล์วิดีโอขนาด 5 GB จากบ้านไปให้เพื่อนร่วมกลุ่ม
  4. ทีมกู้ภัยต้องออกปฏิบัติหน้าที่ในพื้นที่ป่าเขาที่ไม่มีเสาสัญญาณโทรศัพท์

ให้แต่ละกลุ่มนำเสนอว่าควรใช้เทคโนโลยีใด โดยให้เหตุผลตามเกณฑ์: ⚡ ความเร็ว 📍 ระยะทาง 💰 ค่าใช้จ่าย 🔒 ความปลอดภัย

กิจกรรมที่ 3: สำรวจเครือข่ายรอบตัวในโรงเรียน

ให้นักเรียนเดินสำรวจบริเวณโรงเรียน แล้วสังเกตว่าพบอุปกรณ์ Router, Switch, Access Point หรือสาย LAN อยู่ที่จุดใดบ้าง จากนั้นวาดแผนผังเครือข่ายโรงเรียนแบบสังเขปลงในสมุด (หมายเหตุ: กิจกรรมนี้เน้นการสังเกตเชิงกายภาพ ห้ามเจาะระบบหรือสอบถามรหัสผ่านใดๆ)

11. สรุปท้ายบท

  • องค์ประกอบ 5 ส่วน: การสื่อสารข้อมูลที่สมบูรณ์ต้องมี ผู้ส่ง, ข้อมูล, สื่อกลาง, ผู้รับ และโพรโทคอล
  • เครือข่ายคอมพิวเตอร์: ช่วยให้อุปกรณ์แลกเปลี่ยนข้อมูลและแบ่งปันทรัพยากร (เช่น เครื่องพิมพ์, อินเทอร์เน็ต) ร่วมกันได้อย่างคุ้มค่า
  • ขนาดเครือข่าย: LAN คือเครือข่ายระดับอาคารใกล้เคียง, MAN ระดับเมือง, WAN ระดับข้ามจังหวัด/ประเทศ และ Internet คือเครือข่ายที่ใหญ่ที่สุดในโลก
  • สื่อกลางส่งข้อมูล: แบบมีสาย (สาย LAN, ใยแก้วนำแสง) เหมาะกับความเสถียรสูง ส่วนแบบไร้สาย (Wi-Fi, Bluetooth, 5G) เน้นความสะดวกคล่องตัว
  • อุปกรณ์เครือข่าย: Switch เชื่อมอุปกรณ์ภายในวง LAN, Router หาเส้นทางเชื่อมต่อข้ามเครือข่าย และ Access Point แปลงสายเป็นสัญญาณ Wi-Fi
  • โพรโทคอล: TCP/IP เป็นแกนหลักของการสื่อสาร และควรเลือกใช้งาน HTTPS เสมอเพื่อความปลอดภัยของรหัสผ่านและข้อมูลส่วนบุคคล

12. คำศัพท์สำคัญ (Glossary)

Network (เครือข่าย)
ระบบที่เชื่อมต่ออุปกรณ์อิเล็กทรอนิกส์ตั้งแต่ 2 เครื่องขึ้นไปเข้าด้วยกัน เพื่อการสื่อสาร แลกเปลี่ยนข้อมูล และใช้ทรัพยากรฮาร์ดแวร์/ซอฟต์แวร์ร่วมกัน
LAN (Local Area Network)
เครือข่ายท้องถิ่นในพื้นที่ขนาดเล็ก เช่น ภายในห้องเรียน บ้าน หรืออาคารเดียวกัน มีอัตราการรับส่งข้อมูลเร็วและมีข้อผิดพลาดต่ำ
WAN (Wide Area Network)
เครือข่ายบริเวณกว้าง ครอบคลุมพื้นที่ระดับอำเภอ จังหวัด ประเทศ หรือข้ามทวีป เช่น เครือข่ายสาขาของธนาคาร
Router (เราเตอร์)
อุปกรณ์เครือข่ายที่ทำหน้าที่ค้นหาและกำหนดทิศทางการเดินทางที่ดีที่สุดสำหรับข้อมูล เพื่อส่งต่อแพ็กเก็ตข้ามระหว่างเครือข่ายต่างชนิดกัน
Switch (สวิตช์)
อุปกรณ์รวมสัญญาณสาย LAN ที่ฉลาดกว่า Hub โดยสามารถส่งข้อมูลตรงไปยังพอร์ตของเครื่องรับปลายทางได้อย่างแม่นยำ
Protocol (โพรโทคอล)
กฎระเบียบ ข้อบังคับ หรือมาตรฐานที่กำหนดขึ้นเพื่อให้คอมพิวเตอร์และอุปกรณ์ระบบเครือข่ายเข้าใจตรงกันและสื่อสารกันได้อย่างราบรื่น
Server (เซิร์ฟเวอร์ / เครื่องแม่ข่าย)
เครื่องคอมพิวเตอร์ประสิทธิภาพสูงที่ทำหน้าที่ให้บริการข้อมูล ทรัพยากร หรือโปรแกรมแก่เครื่องลูกข่าย (Client) ตลอดเวลา

13. แบบทดสอบท้ายบท

เลือกคำตอบที่ถูกต้องที่สุดเพียงข้อเดียว แล้วกดปุ่ม “ตรวจคำตอบ” ด้านล่าง

3. อุปกรณ์เครือข่ายใดทำหน้าที่เชื่อมเครือข่ายต่างชนิดและเลือกเส้นทางการเดินทางที่ดีที่สุดให้ข้อมูล?
