## เปิดทดลอง

ดับเบิลคลิก `Techno-DT-M1-Offline.html` ใน Chrome หรือ Edge โดยเก็บ `app.css`, `app.js`, `course-data.js` และโฟลเดอร์ `assets` อยู่ข้างไฟล์นี้ ไม่ต้องติดตั้งหรือเปิดเซิร์ฟเวอร์ และไม่ต้องใช้อินเทอร์เน็ต

หากได้รับ ZIP ให้แตกไฟล์ทั้งโฟลเดอร์ก่อนเปิด HTML ไม่เปิด HTML จากใน ZIP โดยตรง

1. เมื่อเปิดเว็บหรือรีเฟรช จะพบหน้าเลือกบทบาทก่อนเสมอ แม้ลิงก์เดิมชี้ไปบทเรียน เลือก **นักเรียน** เพื่อเลือกชื่อหรือสร้างแฟ้มทดลอง เลือก **ผู้เข้าชม** เพื่อสำรวจ หรือเลือก **ครู** เพื่อเข้าพื้นที่ครู
2. เปิดบท → อ่านเนื้อหา → ทดลอง → เขียนชิ้นงาน → ส่งให้ครู
3. เมนู **ครู** เปิดพื้นที่ครูเต็มหน้า เพื่อตรวจงานในเครื่องเดียวกัน
4. หากครูอยู่คนละเครื่อง ผู้เรียนกด **ดาวน์โหลดไฟล์ส่งครู** ครูนำเข้าใน **ตรวจชิ้นงาน** เมื่อตรวจแล้วครูดาวน์โหลดข้อเสนอแนะ ผู้เรียนนำเข้าในแท็บ **ข้อเสนอแนะ**
5. เมนู **แฟ้มของฉัน** ส่งออกแฟ้มผู้เรียนเพื่อเปลี่ยนเครื่อง เมนู **ครู → สำรองและจัดการข้อมูล** สำรองทั้งห้องได้

## มีอะไรให้ทดลองแล้ว

- หน้าแรกเลือกบทบาท 3 การ์ดตามรูปแบบ ป.2 ปรับธีมให้เหมาะกับมัธยม ใช้ไอคอนเดิมแบบไฟล์แยก ไม่ฝัง Base64 แล้วจึงเข้าฐานภารกิจ
- ฐานภารกิจธีมดาวพฤกษากลไก ใช้ Techno ถือดาบและบอสที่มีอยู่แล้ว ไม่มีการเจนภาพใหม่
- 7 บท / 10 หัวข้อ / 20 กิจกรรม นำเนื้อหาล่าสุดจาก `STUDENT_LESSONS.json` มาใช้
- แต่ละบทมีภารกิจ เรียนรู้ ทดลอง ชิ้นงาน ข้อเสนอแนะ และโครงลานบอส
- เนื้อหาอ่านต่อเนื่องหน้าเดียว พร้อมคำสำคัญ ตัวอย่างทีละขั้น จุดเข้าใจผิด และคำอธิบายตรวจตนเอง กดสารบัญเพื่อเลื่อนไปหัวข้อได้
- กิจกรรมต่างรูปแบบ: สำรวจและกำกับรายการ เรียงเหตุผล เปลี่ยนบริบท ประกอบระบบ วิเคราะห์จุดเสีย เลือกวัสดุในงบ วางแผนเครื่องมือ วงจรจำลอง ล้อและเพลา เขียนปัญหา เปรียบเทียบแนวทาง วาดแบบกำกับขนาด เรียงแผน ตรวจพร้อม บันทึกผลสามรอบ วิเคราะห์การปรับปรุง และเรียงแฟ้มหลักฐาน
- ช่องวาดแบบรองรับเมาส์และสัมผัส มีข้อความอธิบายทดแทนสำหรับผู้ไม่สะดวกวาด
- ชิ้นงานเดี่ยวต่อเนื่องเรื่องที่จัดเก็บอุปกรณ์โต๊ะเรียน มีงานร่าง ฉบับส่ง เวอร์ชันแก้ไข รูบริก คะแนน และข้อเสนอแนะ
- พื้นที่ครู: ภาพรวมงานและความก้าวหน้า ปีการศึกษา ภาคเรียน ห้อง วางรายชื่อจาก Excel พร้อมตรวจซ้ำก่อนเพิ่ม แก้รายชื่อโดยคงรหัสแฟ้ม สุ่มชื่อไม่ซ้ำ จัดกลุ่มตามจำนวนกลุ่ม ส่งออกคะแนน CSV สำรอง/คืนข้อมูล และล้างเฉพาะแฟ้มหรือทั้งต้นแบบหลังยืนยัน
- คะแนนชิ้นงานจากครูแยกจากสถานะอ่าน/บันทึกกิจกรรม ไม่มีการให้คะแนนความเข้าใจจากการคลิกครบ

## ภาพและขอบเขตที่ยังเว้นไว้

`image-plan.json` ระบุพื้นที่ภาพเนื้อหา **30 จุด** พร้อม brief และตำแหน่ง ทั้งหมดมีสถานะ `planned_not_generated` และ `runtimeUrl: null` หน้าเรียนแสดงกรอบรอภาพพร้อมคำอธิบาย ใช้รายการสถานการณ์ทดแทนภาพในกิจกรรมสำรวจชั่วคราว

ภาพตัวละครเดิมอยู่ใน `assets/*.webp` เป็นไฟล์แยก ไม่มี Base64 และไม่มี request ออกเครือข่าย ตัวละครพระเอกแปลงจากเฟรมเดิม บอสตัดเฟรมหน้าตรงจากชีตที่กำหนดแล้ว การจัดช่องภาพ/ฉาก/ปกจริงและ Drive URL เป็นงานรอบถัดไปตามแผนเดิม ไม่ใช้กรอบ placeholder แทนภาพจริงในฉบับเผยแพร่

ลานบอสเป็น **โครงพื้นที่และรายชื่อบอส** ยังไม่มีเกมต่อสู้ ปุ่ม Z/X/Space/ลูกศรเป็นคำอธิบายแบบที่วางแผน ไม่ได้ผูกกับเกมในรอบนี้ ยังไม่เชื่อม GAS, Google Drive runtime, บัญชี หรือฐานข้อมูลออนไลน์ และยังไม่รองรับอัปโหลดไฟล์ PDF/ภาพงานจริงเข้าแฟ้มในเว็บ ช่วงทดลองส่งข้อความ แบบร่าง และหลักฐานจากกิจกรรมด้วยไฟล์ JSON ได้

## ข้อมูลออฟไลน์

- เก็บใน `localStorage` คีย์ `krukan-dt-m1-offline-v1` แยกจากประถม
- หน้าครูยังไม่มีระบบยืนยันตัวตน ทุกคนที่เปิดเครื่องเดียวกันเข้าถึงได้ ควรใช้ข้อมูลสมมติทดสอบ
- ใช้ต้นแบบนี้ทีละแท็บเพื่อป้องกันการเขียนข้อมูลทับกัน ยังไม่มีการซิงก์หลายแท็บหรือหลายเครื่อง
- สำรองก่อนล้างเบราว์เซอร์ ย้ายโฟลเดอร์ หรือเปลี่ยนเครื่อง เบราว์เซอร์แต่ละชนิดอาจจัดเก็บข้อมูลของ `file://` ต่างกัน
- ถ้าพื้นที่บันทึกเต็มจะเตือนให้ส่งออก ถ้าข้อมูลเดิมอ่านไม่ได้ จะหยุดเขียนทับข้อมูลเดิมจนกว่าจะนำเข้าข้อมูลสำรองหรือล้างต้นแบบ
- การนำเข้าตรวจชนิด รุ่น เจ้าของงาน รหัสฉบับ และคะแนนก่อนใช้ แต่รูปแบบนี้ไม่ใช่เอกสารลงลายมือชื่อ จึงยังไม่ใช้แทนสิทธิ์ตรวจงานฝั่งเซิร์ฟเวอร์
- จำนวน 20 คาบเป็นแผนร่าง ต้องตรวจให้ตรงหลักสูตรสถานศึกษาและทดลองกับผู้เรียนก่อนใช้จริง
