# DT M1 generated lesson illustrations

30 distinct lesson illustrations were generated in five 3×2 contact sheets and cropped into individual WebP files. Full PNG source sheets and the visual QA overview are preserved in `contact-sheets/`. See `manifest.json` for lesson mapping, local paths, crop cells, dimensions, file sizes, and Google Drive links.

The individual images and contact sheets are staged in Google Drive folder [M1-Course-Assets](https://drive.google.com/drive/folders/1BaK1eEBmtb3dX33r_sBPgr5JayzGVuiX). The images are not embedded as Base64 and are not wired into the website yet. Each `runtimeUrl` remains empty until the GAS image-serving approach is selected during integration.

The rider reference was `techno-secondary-4weapons/sword/frames/00-ready.png`; Techno appears as a supporting character in selected illustrations.
